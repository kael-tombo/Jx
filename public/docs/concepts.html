Draft

Concepts

A draft design of the manifest, lockfile, resolver and conflict policy. None of it is released.

This page describes intended behaviour. The schema is not final and no command described here is part of a release.

Manifest

A project has one manifest, project.toml. It names the project, pins a JDK and records dependencies. It also holds the entry point for jx run.

Illustrative manifest. Not a final schema. 
[project]
name = "hello"
version = "<version>"
jdk = "<version>"

[dependencies]
guava = "com.google.guava:guava:<version>"

[run]
main = "app.Main"

Dependency keys are local aliases. Values are Maven coordinates: group, artifact, and a version or a placeholder for one. The final rules for ranges, overrides and platforms are not settled.

Lockfile

The lockfile, jx.lock, records the exact artifacts a build resolved. It is written by jx, not by hand. It is meant to make a build on another machine select the same versions.

Each entry would carry a checksum. A changed checksum is a hard error, not a warning. A lockfile that silently accepts a different artifact is worse than no lockfile.

Resolver

The resolver reads POM metadata from Maven Central and builds a dependency graph. It applies the conflict policy, then writes the lockfile. jx tree and jx why would explain the result.

Resolution is planned to be native to jx. Maven and Gradle are not required to resolve a graph.

Conflict policy

When two dependencies ask for different versions, the proposed policy is:

  • Within one major version, choose the highest compatible version.
  • Across majors, stop with a hard error. The project must choose.

This is a proposed design, not an accepted guarantee. It favours a visible failure over a silent downgrade. Every replacement would be named in the resolution report.

Read the glossary entries for resolver and lockfile.

What is not decided

Repository configuration, mirrors, credential storage, the final manifest schema and the exact lockfile format are open. They will be recorded as decision records when they settle.
