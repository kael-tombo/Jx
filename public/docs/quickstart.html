Quickstart

The planned first five minutes with jx. There is no release yet.

Target experience. Nothing on this page is a recording or a supported install.

The target

One terminal. No Java installed. Five minutes later, a program runs. That is the whole promise the design is built around.

The first release is planned for plain Java. The same jx new and jx run flow is the target for Spring Boot, Quarkus, Vert.x and Jakarta EE later.

  1. Open a terminal

    There is no installation method yet. When a release exists, the install step will be documented here with the download source and its checksum.

  2. Create a project

    jx would write a manifest, a source file and a pinned JDK.

    Target command
    jx new hello && cd hello

  3. Run it

    The first run would fetch the pinned JDK, compile the source and start the program.

    Target command
    jx run
    Illustrative output
    Hello, world!

  4. Make a change

    Edit the main class, then run the same command again. The design target is a warm run that skips work that did not change.

    Target command
    jx run

  5. Look at the project

    Two files carry the project. The manifest records what you asked for. The lockfile records exactly what was resolved.

    Read Concepts for the shape of both files.

What is not here

No install command, no download and no release. The quickstart is a target for the first release, not a supported install. The roadmap names the milestones that would change that.
