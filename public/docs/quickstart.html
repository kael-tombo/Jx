Quickstart

The first five minutes with jx. V1 is implemented; release binaries are pending.

These commands are implemented in the source tree. Until release binaries publish, build from source; this is not yet a supported install.

The first five minutes

One terminal. No Java installed. Five minutes later, a program runs. That is the whole promise V1 is built around.

V1 covers plain Java. The same jx new and jx run flow is the target for Spring Boot, Quarkus, Vert.x and Jakarta EE later.

  1. Open a terminal

    The release archives and installers publish from the v1.0.0 tag. Until then, build from source with a Rust toolchain (edition 2024); the archive step will be documented here with its download source and checksum when the release is published.

    Build from source
    cargo build --release

    The binary is under target/release/; add that directory to PATH or call the binary directly.

  2. Create a project

    jx writes a manifest, a source file and a pinned JDK.

    Command
    jx new hello && cd hello

  3. Run it

    The first run fetches the pinned JDK, compiles the source and starts the program.

    Command
    jx run
    Illustrative output
    Hello, world!

  4. Make a change

    Edit the main class, then run the same command again. A warm run skips work that did not change.

    Command
    jx run

  5. Look at the project

    Two files carry the project. The manifest records what you asked for. The lockfile records exactly what was resolved.

    Read Concepts for the shape of both files.

Scripts and existing projects

Scripts and single-file programs stay with JBang. Install JBang first; jx script hands it the file and its arguments, and uses the project's pinned JDK when there is a manifest.

Delegate a script
jx script hello.java Max

Existing Maven and Gradle builds convert with jx import. The same command also reads a Java-only, single-module jot.toml, including a version catalog and annotation processors, and prints every approximation before writing.

Import and inspect
jx import jot.toml --dry-run

Release status

No tagged release exists yet, so there is no supported install. The commands on this page are implemented in the source tree and covered by the repository tests. The archive, checksum and installer step will be added when v1.0.0 is tagged.
