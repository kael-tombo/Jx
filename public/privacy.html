Privacy.

This site is a static design preview. It does not track you.

What this site collects

No analytics, no cookies, no advertising and no fingerprinting. Fonts, styles and scripts are served from this site, not from a third party.

The only local storage is a theme choice. It stays in your browser, is never sent anywhere, and can be cleared with your browser data.

Host logs

The host may keep standard request logs. These can include an IP address, the time, the requested path and the user agent. The project does not use them to build profiles.

Email and updates

There is no email form and no newsletter. If one is added, it will post only to a disclosed endpoint with a plain consent sentence. The endpoint and the provider will be named on this page first.

Links to other sites

Links to GitHub leave this site. GitHub has its own privacy policy and its own data practices. This site does not embed GitHub content, badges or tracking pixels.
