Contributing

How to follow, question and help with the design while it is still open.

There is no published contribution process yet. This page describes what help is useful now, not a process that exists.

Follow

The repository is public. Watch it on GitHub for changes to the design notes and the roadmap. No release is scheduled.

Discuss

The most useful contribution now is a sharp question. If a decision record assumes something that is not true for your project, say so and name the case. A counterexample is worth more than a preference.

Use the repository's issue tracker if it is open. Otherwise, read the decision records and respond with the case the record missed.

Where help is useful

  • Counterexamples from real Maven and Gradle projects, especially unusual layouts and plugin-dependent builds.
  • Reviews of the smoothness tests: are they the right tests for a first release?
  • Accessibility feedback on this site. The accessibility page says what has and has not been checked.
  • Honest limits. If the vision page is too generous about what jx will not match, say where.
