Proposed plan

Roadmap.

Milestones M0 to M8, the gates between them, and the honest status of the V1 plan. Nothing is released.

Estimates assume a small team and will change. No dates are set. No milestone is released.

Milestones

  1. M0Not released

    Foundations

    Workspace, continuous integration, decision records, configuration and diagnostics. The base every later milestone sits on.

  2. M1Not released

    Toolchain and hello

    JDK download and pin, project scaffolding, and a first build and run with no Java installed.

  3. M2Not released

    Repository and POM model

    Maven Central client, cache, checksums, a POM model and dependency version ordering.

  4. M3Not released

    Resolver

    Dependency graph, conflict policy, a reproducible lockfile, and the tree and why commands.

  5. M4Not released

    Build and test

    javac integration, fingerprints that skip unchanged work, resources, and a JUnit launcher.

  6. M5Not released

    Run and package

    Main discovery, a run command, distributions and a jar. Export to Maven.

  7. M6Not released

    Runtime trimming

    jdeps and jlink, with a fallback when a project cannot be trimmed. This is optional packaging for deployment; it does not change what the JDK ships.

  8. M7Not released

    Maven and Gradle interop

    Import, compatibility mode, delegate mode, and exports in both directions.

  9. M8Not released

    Release hardening

    Documentation, an install path, a security review and a launch checklist.

Decision gates

A milestone cannot close because code exists. It closes when its gate passes.

  • Gate Open

    Resolver parity with Maven

    A representative set of POMs resolves to the same versions Maven selects. Until this holds, the resolver is not done.

  • Gate Open

    Happy-path coverage

    A new user completes the hello flow on a machine with no Java installed, following only the published quickstart.

  • Gate Open

    User preference

    People choose jx for a new project after trying it beside their current workflow. No such trial has run.

How to read this page

Statuses describe the public plan, not private progress. A milestone marked not released has no public release. Estimates will change, and the page will say when they do.

The landing page carries a short version of this timeline. The vision explains the tests behind the gates.
